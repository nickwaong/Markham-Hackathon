# Markham Link / 万锦生活通

An interactive, browser-local settlement planner for newcomers to Markham.

## Run locally

Open `dist/index.html` in a modern browser. No account, API key, installation, or server is needed.

## Prototype capabilities

- Text-input language/script detection for the live demo
- First-seven-days and first-30-days checklist
- Official-service links for IRCC, Service Canada, ServiceOntario, CRA, York Region and 211
- Personal tasks and browser-local completion tracking
- Optional browser notification permission flow

## Important scope

Language detection, reminders and saved progress operate only in the current browser for this prototype. A production service would require consent-based voice/translation services and regularly verified public-service data.
